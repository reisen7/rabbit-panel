# 更新日志

## v2.3.0 (2026-10-08)

### 多节点
- Worker 启动后向 Master 注册并定时心跳，节点列表可以显示在线 Worker
- Master 可在顶部和侧边栏切换节点，容器、网络、存储卷、Compose 和仓库配置都跟随当前节点操作
- Worker 不再提供管理界面，只保留给 Master 调用的接口
- Master 节点名称默认显示为 `master`，可用 `NODE_NAME` 覆盖
- Worker 增加 `NODE_ADDRESS`，填写 Master 能够访问到的地址

### Compose
- 新建后尚未启动的项目状态显示为已停止

### 登录
- 放大登录验证码，并把字符放在图片中间

### 仓库
- 保存的仓库账号会在拉取对应地址的镜像时自动使用，包括创建容器时的拉镜像
- 编辑仓库时密码留空会保留原密码，修改地址不再留下旧记录
- 测试连接会使用已保存的密码，并识别私有仓库的令牌认证
- Docker 配置里允许 HTTP 的仓库改为从仓库管理中选择地址

## v2.2.5 (2026-08-08)

- 新增 `RABBIT_UPDATE_CHECK_DISABLED` 环境变量，设置为 `true` 时跳过更新检查，不再请求 `MANIFEST_URL`

## v2.2.4 (2026-05-13)

### 更新系统
- 重构二进制更新流程，拆分为“下载更新”和“应用更新”两个阶段
- 更新进度改为真实下载进度，优化状态恢复、失败清理和详细日志输出
- 新增更新应用接口，支持下载完成后再备份、替换并重启服务
- 修复 systemd 应用更新、自定义部署路径、残留任务状态和脏文件导致的异常
- 修复当前已是最新版本时仍可触发更新的问题

### AI 运维助手
- 恢复 AI 运维助手核心能力，补回容器、镜像、网络、存储卷、Compose 和系统状态工具
- 修复 API Key 掩码保存逻辑，避免重复保存时覆盖原始密钥
- 修复历史记录为空、清空无效和会话加载异常的问题
- 优化助手配置与聊天浮窗交互

### 容器与调度
- 修复容器列表统计字段异常导致的页面报错和布局错乱
- 修复容器全量日志、实时日志、终端执行输出、容器详情和资源统计链路
- 完善容器重建、更新、文件管理和本地调度创建逻辑
- 创建容器支持右侧任务日志、自动滚动、最小化恢复和取消任务
- 修复单点模式节点为空、最佳节点缺失以及调度返回空容器的问题

### Compose / 仓库 / 存储卷 / Docker 配置
- 统一仓库、存储卷、Compose、Docker 配置相关接口风格并补齐缺失能力
- 修复仓库编辑误新增、删除后数据未刷新等问题
- 修复 Compose 项目选择、状态查询、文件读取和动作日志输出
- 修复 Docker 配置页面数据为空的问题，增强接口部分失败时的页面容错

### 网络与资源显示

## v2.2.0 (2026-05-11)

### 更新系统
- 新增版本信息注入：`Version`、`Commit`、`BuildTime`
- 新增更新检查、忽略版本、立即更新接口
- 更新检查改为读取 `https://reisen7.github.io/rabbit-panel/latest.json`
- 新增二进制更新逻辑，支持按架构下载、校验 SHA256、备份旧版本并重启服务
- 新增 Docker `latest` 部署更新流程，固定 tag 仅提示不自动执行
- 前端新增更新通知、更新弹窗、更新设置页和顶部版本显示

### 发布自动化
- 新增统一 `release.yml` 发布流水线
- 支持打 tag 后自动构建前端和 Linux 二进制
- 支持自动创建或更新 GitHub Release
- 支持自动生成并上传 `sha256sums.txt`
- 支持自动构建并推送 Docker 镜像
- 支持自动生成 `latest.json` 并发布到 GitHub Pages

### 资源使用检测
- 镜像列表新增“正在使用 / 未使用”状态与引用容器数
- 网络列表新增使用状态与连接容器数量
